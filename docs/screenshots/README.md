# Screenshots

Put your app screenshots here and they'll show up in the main README:

- `login.png`
- `dashboard.png`
- `tasks.png`
- `detail.png`
- `form.png`

**How to capture:**
- **Expo Go / phone:** open each screen and take a normal phone screenshot, then copy the PNGs here.
- **Installed APK:** same — screenshot on the device.
- **Web:** run `npx expo start --web`, resize the browser to a phone width, and screenshot.
